# せどり在庫管理 v1

JANコードをカメラで読んで入庫・出庫を記録する、スマホ向けの在庫管理アプリ(PWA)です。
データは端末内(IndexedDB)にだけ保存され、GitHubには置かれません。

## 公開手順(GitHub Pages)
1. GitHubで新しいリポジトリを作る(Publicで可。例: `stock`)
2. このzipを展開して、中のファイルをすべてリポジトリ直下にアップロードする
   - stock.html / stock.js / stock-version.js / stock-sw.js / stock.webmanifest / stock-icon-180.png / stock-icon-192.png / stock-icon-512.png
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

## 端末に入れる
- iPhone: Safariで開く → 共有ボタン →「ホーム画面に追加」
- Android: Chromeで開く → メニュー →「アプリをインストール」(または設定画面のボタン)
- **最初の1回はオンラインで開いてください。**以降はオフラインでも起動します。

## 使い方
- スキャン画面で「入庫/出庫」と倉庫を選び、「カメラを開始」でバーコードを枠に入れる
- 数量は ＋/− か、数字をタップして入力
- 同じバーコードを続けて記録するには、一度カメラから外す(または数量を使う)
- 未登録のJANを入庫すると商品名の入力が出る。出庫は登録済みの商品のみ
- 直前の記録は「取り消し」で戻せる。古い履歴は在庫画面の商品詳細から削除できる
- カメラが使えない時は「JANを手入力」で記録できる

## バックアップ(重要)
設定画面の「JSONで書き出し」を週1回ほど実行してください。機種変更やデータ消失時は「JSONを読み込み」で復元できます。

## 仕様メモ
- 在庫数は入出庫履歴の合計から計算
- 出庫時に選択中の倉庫に在庫が足りない場合、在庫のある倉庫を選ぶ画面が出る
- 書籍の2段目バーコード(191/192始まり)は自動で無視
- バーコードの読取: Android(Chrome)は標準機能、iPhoneは ZXing(CDNから取得し、以後キャッシュ)

## バージョン管理(設定画面 →「バージョン」)
- 使用中のバージョン、「最新バージョンを確認」「更新する」、「前のバージョンに戻す」「最新バージョンに戻す」がある
- 端末には「今のバージョン」と「1つ前のバージョン」の2つを保存しているので、戻すのはオフラインでもできる(データはそのまま)
- アプリが開けなくなったら、アドレスの最後に `?rollback`(前の版)/ `?latest`(最新版)を付けて開く
- バージョンは公開日(`stock-version.js` の `version` を `"2026.11.27"` の形で書く。同じ日の2回目以降は `"2026.11.27.2"`)
- **更新を公開するときは、`stock-version.js` の `version` を必ず新しい日付にする**。ここが変わらないと端末側は更新に気づかない。`notes` に変更内容を書くと確認画面に表示される

## 買取価格の表示(任意・買取X API)
- 設定画面の「買取価格(買取X・任意)」に [買取X Open API](https://kaitorix.app/open/) のAPIキーを入れて保存すると有効になる
- 入庫で未登録のJANを読むと、商品名を買取Xから自動入力する
- 入庫・出庫の記録カードに最高買取価格を表示し、「買取価格一覧」で店舗ごとの価格を見られる(「今回の記録」の行や在庫画面の商品詳細からも開ける)
- 無料プランは1日30回・1秒1回まで。同じJANは6時間、保存した結果を使う。キーは端末内(localStorage)だけに保存し、JSONバックアップには含めない

## 各買取店のサイトでJAN検索 / 写真で読む
- 記録カード・商品詳細・買取価格一覧の「店のサイトで検索」で、買取X・家電市場・携帯空間などの検索ページをJAN入りで開く(リンクを開くだけで、自動取得はしない)
- スキャン画面の「写真で読む」は、端末のカメラで撮った静止画からJANを読む(動画で読めないときの予備)
- スキャン画面の一番下に使用中のバージョンを表示し、新しい版があれば「更新する」ボタンが出る
