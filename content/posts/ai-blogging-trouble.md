# AIとiPhoneでのブログ自動化：発生したトラブルと試行錯誤の記録

Nov 20, 2026 · @K

本記事では、GitHubのIssueとAIを使ってブログ記事を作成・公開する過程で直面したトラブル、サービス制限、およびiPhoneのみでの運用における試行錯誤の履歴をまとめます。

---

## 1. 検討したAIサービスの制限とつまずき

Issueに指示を書いてAIにPRを作らせるサービスについて、多くのサービスが無料枠の終了や有料プラン限定であることが判明しました。

| サービス | 起動方法 | 無料での利用可否 | 発生した問題・特徴 |
| --- | --- | --- | --- |
| Jules (Google) | Issueに「jules」ラベル | 無料枠あり | 12月31日で終了。11月11日以降は新規作業不可 |
| GitHub Copilot クラウドエージェント | IssueをCopilotに割り当て | 不可の見込み | 公式ページでは有料プラン向け |
| Claude Code (GitHub Actions) | 「@claude」とコメント | 不可 | Anthropic APIの従量課金が必要 |
| OpenAI Codex | 「@codex」とコメント | 不可の見込み | 無料のChatGPTにはクラウド機能なし |
| opencode | 「/opencode」とコメント | 本体は無料の見込み | Gemini無料キーでの動作は未確認 |

また、OpenHands設定時にも以下のエラーや警告に遭遇しました：
- `repository variable LLM_MODEL is not set`: モデル名の変数が空で、アクションが開始直後に停止。SecretsではなくVariablesに設定が必要。
- `Node.js 20 is deprecated`: 古いNode.jsランタイムの警告。

---

## 2. iPhone単体での情報収集と公開における限界

iPhoneと無料枠だけで完結させようとした際、以下の壁に突き当たりました。

- **X (Twitter) の収集**: 公式APIの無料枠が非常に小さいため自動取得は断念。手動でリストやブックマークから「メモ」アプリに集約。
- **Claudeのアーティファクト共有**: 無料プランでは共有機能（公開リンクの作成）が含まれておらず、リンクを作ることができませんでした（MarkdownやPDFのエクスポートのみ可能）。
- **GitHubへの直接リポジトリ作成**: Claudeの連携機能ではリポジトリの新規作成やファイル管理に制限があり、iPhoneのSafariから手動でGitHub Pagesを設定する必要がありました。

---

## 3. 教訓とまとめ

無料枠やモバイル環境のみでの自動化には多くの制約があり、モデルの選定や適切な手順を踏まないと動作しません。これらの試行錯誤を経て、最終的な解決手順へとたどり着きました。
